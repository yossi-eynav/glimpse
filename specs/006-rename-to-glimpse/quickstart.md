# Quickstart & Validation: Rename the app to Glimpse

## Automated checks

1. **No old names in live files** (FR-007, SC-002). The search must print nothing:

   ```sh
   grep -rnIiE "google photos wallpaper|google-photos-wallpaper|photowallpaper|photo wallpaper|pw-helper" \
     --exclude-dir={node_modules,.git,dist,build,out,specs} --exclude=package-lock.json .
   ```

   `package-lock.json` is regenerated by `npm install` after the `package.json` rename. Check
   it separately with `grep -c google-photos-wallpaper package-lock.json`, which should print 0.

2. **Tests and types** (FR-008, SC-003). Run `npm test` and `npm run typecheck`. Both pass, with
   at least 232 tests.

3. **Native build** (C2–C5). Run `npm run build:native`. It produces `build/glimpse-helper` and
   `build/Glimpse.saver`. Then check:
   - `plutil -p build/Glimpse.saver/Contents/Info.plist` shows `CFBundleExecutable` `Glimpse`,
     `NSPrincipalClass` `GlimpseSaverView` and `CFBundleName` `Glimpse`.
   - `nm build/Glimpse.saver/Contents/MacOS/Glimpse | grep GlimpseSaverView` is not empty.

4. **Package** (N1, N3). Run `npm run make`, which needs a local `config/google.json`. Then:
   - `out/Glimpse-darwin-universal/Glimpse.app` exists.
   - `plutil -p …/Glimpse.app/Contents/Info.plist` shows `CFBundleIdentifier`
     `com.yossieynav.glimpse`.
   - `Contents/Resources/` contains `glimpse-helper` and `Glimpse.saver`.

## Manual validation (SC-001, SC-004, SC-005)

| # | Check | Expected |
|---|-------|----------|
| 5 | Run `npm start`. Hover over the menu bar icon, sign in, choose Turn off, then Turn on | The tooltip says "Glimpse", the browser's done page says "return to Glimpse", and the Turn off notice names Glimpse |
| 6 | Turn on "Use for screensaver" | The notice says to select "Glimpse". Screen Saver settings lists **Glimpse**, and the preview shows the current photo (C1) |
| 7 | Look in `~/Library/Application Support/` | `Glimpse/` exists. `Google Photos Wallpaper/` is untouched (start fresh, FR-009) |
| 8 | Delete the old folder and `~/Library/Screen Savers/PhotoWallpaperSaver.saver` by hand | Only Glimpse is listed in Screen Saver settings |
| 9 | Compare every path in the README and PRIVACY.md with the disk after steps 5–6 | They all exist under the names given (SC-004) |
